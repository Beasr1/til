# Blog topics

- [ ] **The card forgot its challenge** — NFC mutual auth passed on a dip and failed on a tap from home: the card lost its challenge while the link sat idle through the backend round trip. A keep-alive every 100 ms fixed it, and then the twist: the culprit was the reader's old firmware wiping idle cards, and an update fixed it without the keep-alive.
- [ ] **Your office network is a test fixture** — a timing bug that never showed in the office, because the office's direct tunnel kept the round trip short.
- [ ] **One chip, two ATRs** — a card that read on contact was "not recognised" when tapped, because the table had its contact ATR but not the contactless one PC/SC synthesises.
- [ ] **The test vector in the appendix** — a feature-flagged secure-messaging path that no CI built had rotted, and the spec's worked example caught the padding bug left in it.
- [ ] **Adding a field to a format you can't change** — one optional field in a frozen host–guest wire format, tested old-to-new and new-to-old.
- [ ] **Audit the right copy of the source** — a port comparison concluded the predecessor lacked a feature it had, because it read the older of two copies.
- [ ] **The revoked key that still worked** — revoking a credential deleted its cache entry and returned success, yet the old credential kept authenticating. The delete had computed the cache key with a different function from the one used on write, so it removed a key that never existed.
- [ ] **Code zero** — an optional numeric field kept coming back 'missing' for one record type, and only that one. Zero was a valid code, and a truthiness check had been treating it as absent all along; the fix with `??` then missed the NaN that `parseInt` returns.
- [ ] **The audit trail that went quiet** — a route rewrite shipped cleanly, every test passed and nobody complained. Months later someone asked for an audit record and found none: the audit write had lived inside the old handlers, and its best-effort failure path logged nothing.
- [ ] **The coverage that fell while nothing changed** — line coverage dropped sharply on a branch whose tests were all green. No test had been lost; a wrapper was mangling the arguments passed to the instrumented test binary, and an environment variable the runner reads itself fixed it.
- [ ] **A shell command that YAML read as a map** — a CI job failed with an error about a type, not a command. One unquoted script line contained a colon followed by a space, so YAML parsed it as a key/value pair and the shell never saw it.
- [ ] **set -e ate the exit code** — a script meant to print a tool's output and then report its exit status printed nothing at all on failure. Under `set -e`, the failing command substitution aborted the script before the output could be shown, so the signal it existed to report killed it.
- [ ] **A dollar sign in the replacement** — templated output was corrupted only for some inputs. The replacement text was user data, and `String.prototype.replace` interprets `$&` and friends in a replacement string, so the data was rewriting itself.
- [ ] **The check that recorded the failure and let it through** — the verification ran, computed the right answer and stored it in the audit record. No branch ever denied on it, so a failed check was faithfully logged and the request carried on.
- [ ] **A shuffle you can run backwards** — data was 'protected' by permuting it with a seeded Fisher-Yates shuffle. Anyone who can derive the seed regenerates the same swap sequence and replays it in reverse, so it was obfuscation, not protection.
- [ ] **The UTC fix that changed nothing** — timestamp-signed requests were rejected, and the fix converted the time to UTC before taking the epoch value. An epoch timestamp doesn't depend on time zone at all; the real fault was clock skew or seconds against milliseconds.
- [ ] **The charge event that always said success** — usage was billed for operations that had failed. The event was emitted from an intermediate step with a hard-coded success status, before the real outcome was known, so every exit path looked billable.
- [ ] **Binary through a JSON string** — an upstream document arrived intact on the wire and corrupted in storage, with no error anywhere. It had been treated as text and put into a JSON string, and the encoder quietly replaced every invalid UTF-8 byte with U+FFFD.
- [ ] **The PNG that wasn't** — an image asset rendered in one place and broke in another. Its extension said PNG and the static server labelled it that way, but its magic bytes said AVIF, and decoders go by the bytes.
- [ ] **The placeholder someone else already owned** — a placeholder ID was chosen to mean 'not yet assigned'. A downstream system treated the same value as its own default, so placeholder records quietly merged with real ones; the Nil and Max UUIDs mean different things for a reason.
- [ ] **Backfilling history into a system that is already deciding** — a historical backfill landed in a system that had been making live decisions on incomplete history. The data was right after the load; the decisions made before it were not, and correcting them needed compensating entries, not deletes.
- [ ] **Uninitialising someone else's threads** — a host process crashed inside a third-party library long after a short COM call had returned. COM initialisation is reference-counted per apartment and the multithreaded apartment is process-wide, so pairing init and uninit around one call tore it down under the vendor's threads.
- [ ] **window.close() didn't throw** — a flow wrapped `window.close()` in try/catch to detect when the browser refused. Browsers only let scripts close windows that script opened, and a refused close fails silently, so the catch block never ran.
- [ ] **Every log line twice** — a logger started printing each line twice after a refactor that only added a wrapper. A tee writes once per child, and the wrapper had been teed with the very core it wrapped.
